What you get

One Grocy device with sensors, binary sensors, a to-do list and a calendar. Only the features you use in Grocy show up.

Stock at a glance

Everything in stock with amounts, best-before dates and pictures, plus alerts for expiring, overdue, expired and missing products.

Shopping list to-do

Tick items off in the supermarket, add products by name, or ask Assist. It's a regular Home Assistant to-do list.

Chores, tasks, batteries

Counts with full lists, and "overdue" binary sensors that make reminder automations a one-liner.

Calendar

Grocy's calendar (due products, chores, tasks, batteries and meals) in the Home Assistant calendar view.

Command Center card

Overdue items, pantry by location, chores, tasks and the shopping list with one-tap buttons. Loaded automatically.

Light on Grocy

A tiny "has anything changed?" check every 30 seconds. Data is only downloaded when Grocy says something changed.

Upgrading from 2.x

2.x used the domain grocy and the folder custom_components/grocy, the same as the original custom-components/grocy integration that HACS removed from its list. That's why HACS kept saying the repository was removed. 3.0 has its own domain, grocy_pro.

  1. Update Grocy Pro in HACS and restart.
  2. Add integration → Grocy Pro → Move my old Grocy setup. It reuses your URL and API key, removes the old entry and keeps your sensor.grocy_* entity IDs and history.
  3. In HACS, remove the entry flagged as removed (custom-components/grocy). Delete custom_components/grocy if it's still there. Restart.
  4. Change grocy.* to grocy_pro.* in automations and scripts.
  5. Remove the old /local/grocy-action-card.js dashboard resource: the card now comes with the integration.

Installation

HACS, a restart, and a Grocy API key.

HACS

  1. 1. Click Open in HACS, or add https://github.com/DonTranQuiL/grocy-pro as a custom repository (category Integration).
  2. 2. Download Grocy Pro and restart Home Assistant.
  3. 3. In Grocy: Settings → Manage API keys → Add.
  4. 4. Settings → Devices & services → Add integration → Grocy Pro, then enter the URL, API key and port (9192 for the add-on).
